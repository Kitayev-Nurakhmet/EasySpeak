# EasySpeak 🗣️

**EasySpeak** — это веб-приложение для улучшения навыков разговорного английского с помощью интерактивных диалогов и искусственного интеллекта.

## 📋 Основные функции

### 🔹 Интерактивные диалоги
Практикуйтесь в разговорном английском с AI-собеседником в реальном времени.

### 📱 Адаптивный дизайн
Сайт оптимизирован для всех типов устройств — от смартфонов до компьютеров.

### 🎨 Современный UI/UX
Простота и удобство использования благодаря минималистичному дизайну.

## 🚀 Технологии, используемые в проекте

- **HTML** — структура веб-страницы
- **CSS** — стилизация и адаптивность
- **JavaScript** — обработка изображений и интерактивность

## 🛠 Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone git clone https://github.com/Kitayev-Nurakhmet/EasySpeak.git
   ```
2. Откройте `index.html` в браузере.
